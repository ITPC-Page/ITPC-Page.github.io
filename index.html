Quadrotor Simulation Experiments

We consider three configurations in Gazebo Simulation. Note that in this comparison, log-MPPI serves as both the local trajectory planner and the cascaded controller.

  1. A*+MPPI: path planner + log-MPPI with fixed velocity.
  2. A*+miniS+MPPI: path planner + global trajectory planner + log-MPPI.
  3. A*+ITPC: path planner + proposed ITPC.

The evaluation is structured around the following three research questions.

Q1: Can the proposed FR-MHE achieve accurate joint state and disturbance estimation while maintaining real-time computational performance and robustness?

Quadrupted Robot Experiments

Further ablations account for inherent low-level execution latency and tracking degradation by adopting a multiplicative disturbance model. To validate this, we conduct two sets of experiments on the Unitree Go2 platform, evaluating:

  1. The necessity of incorporating low-level performance into high-level.
  2. The importance of sequential waypoints with target-switching logic, rather than a single subgoal.

Indoor Collision-avoidance Experiments: The left panel shows some failure cases of the nominal navigation model, which easily collides with dynamic obstacles due to uncompensated system latency and tracking errors.

Outdoor Local-minima Experiments: The left panel employs a single waypoint placed a relatively large distance (0.5 m) ahead along the path. This baseline is highly prone to falling into local minima because it often positions the target directly behind an obstacle.
